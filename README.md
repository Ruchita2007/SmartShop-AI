# 🛍️ SmartShop AI

SmartShop AI is an AI-powered smart shopping platform that helps users discover products, search products, manage their shopping cart, and receive budget-based product recommendations.

## 🚀 Features

- 🤖 AI Shopping Assistant
- 💰 Budget-Based Product Recommendations
- 🔍 Product Search Functionality
- 🛒 Add Products to Cart
- ❌ Remove Products from Cart
- 💾 Local Storage for Cart Data
- 💰 Automatic Total Calculation
- 📄 Multi-Page Website
- 💳 Checkout Functionality
- 📱 Responsive Design

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Local Storage

## 📂 Project Pages

- Home Page
- Products Page
- AI Assistant Page
- Shopping Cart Page
- Checkout Page

## 🎯 Project Objective

The objective of SmartShop AI is to provide a simple and personalized shopping experience. The platform helps users find products based on their requirements and budget while providing essential e-commerce features such as product search, cart management, and checkout.

## 💡 What Problem Does It Solve?

SmartShop AI helps users quickly find suitable products based on their shopping requirements and budget. It simplifies the shopping process by providing product search, budget-based recommendations, cart management, and checkout functionality.

## ▶️ How to Run the Project

1. Download or clone the repository.
2. Open the project folder in VS Code.
3. Open `index.html` using Live Server.
4. Explore the SmartShop AI website.
